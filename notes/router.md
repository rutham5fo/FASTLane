# router.py

## Methods

### `load_context(mapper_context=None, cgra_context=None)`
Loads the mapper and CGRA contexts, and initializes the Benes network with the CGRA block size. It also sets the maximum recursion limit for `find_valid_port` based on CGRA radix.

### `add_tracker(block_path_tracker: list[int], block_source_tracker: list[int], port_loc: int, new_node_pe, new_child_pe)`
Adds new child PE and source PE to the block's path and source trackers at a specified port location.

### `del_tracker(block_path_tracker: list[int], block_source_tracker: list[int], port_loc: int, source_pe: int)`
Deletes a source PE and its corresponding child PE from the block's path and source trackers at a specified port location.

### `assert_path_tracker_safe(block)`
Makes sure all destinations belong to the block and are unique within the `blk_path_tracker` list.
- **Destination Uniqueness**: Checks for repeated destinations within a port's tracker.

### `find_conflicting_pe(blk_path_tracker: list[int], blk_src_tracker: list[int], port_loc: int, source_pe: int, child_pe: int)`
Finds a conflicting PE (if any) at a given port location for a specified source and child PE.

### `resolve_conflict(path_type: int, conflict_pe: int, conflict_stack: list[int], recursion_cnt: int=0)`
Recursively resolves conflicts by rotating ports of the conflicting PE and propagating changes to children.
- **Sanity check**: Checks for recursion limit to prevent infinite loops.
- **Conflict Stack**: Adds the current conflicting PE to a stack to track the resolution path.
- **Metadata Rotation**: Rotates the output operation ID, block ID, and port metadata for the conflicting PE.
- **Tracker Update**: Deletes old child PE from trackers and adds the new child PE after rotation.
- **Recursive Resolution**: Recursively calls `resolve_conflict` for any new conflicts generated by the rotation.

### `find_valid_port(path_type: int, block: int, n_pe: int, ch_pe: int, n_opID: int, n_out_opID: list, n_out_blockID: list, blk_path_tracker: list, blk_src_tracker: list, port_meta: list, attempted_ports: list, recursion_cnt: int=0)`
Finds a valid port for routing an edge from a source PE to a child PE, handling conflicts and recursive attempts.
- **Child PE Sanity Check**: Ensures the child PE exists.
- **Recursion Limit**: Checks for recursion limit to prevent infinite loops.
- **Relative PE IDs**: Converts PE IDs in `blk_path_tracker` to relative IDs to avoid aliasing issues with shadow PEs.
- **Port Validity Check**: Determines if a port is valid (not containing the destination PE in its path-set and not already attempted).
- **Free Port Allocation**: If a free port is found, it's consumed, and tracking information is updated.
- **Possible Routes**: If no free port, marks ports as possible routes for later consideration.
- **Displacing Existing Edge**: If no free port, and possible routes exist, it picks an unattempted possible port, displaces the existing edge, and recursively calls itself to place the displaced edge.
- **Conflict Resolution Attempt**: If routing is still unsuccessful, it attempts to resolve conflicts by placing the edge in an unassigned port and calling `resolve_conflict`.

### `route_node_path(dedges, n_name, n_opID, n_pe, n_shadow_pe, n_children, n_blk, n_shadow_blk, data_path_tracker, data_source_tracker, pred_path_tracker, pred_source_tracker)`
Routes paths for a given node to its children, considering data and predicate edges, and handling forward/backward edges.
- **Child Iteration**: Iterates through each child of the node.
- **Path Type Determination**: Determines if the edge being routed is a data or predicate edge.
- **Block Selection**: Selects the appropriate block (main or shadow) based on whether it's a forward edge.
- **Metadata Setup**: Ensures `pe_meta` exists for the selected PE and resets its port metadata.
- **Port Availability Check**: Checks for unmapped ports in the source node.
- **Valid Port Search**: Calls `find_valid_port` to find a suitable port for the edge.
- **Path Tracker Sanity Check**: Performs a sanity check on the block path tracker after routing.

### `run(dot_ctxt=None)`
Runs the router algorithm to establish connections between PEs based on the DFG.
- **Tracker Setup**: Resets and initializes data and predicate path trackers.
- **Node Iteration**: Iterates through each node in the DFG.
- **Shadow Equivalents**: Finds shadow PE and block equivalents for the current node.
- **Fanout Check**: Ensures the fanout of the node does not exceed available ports.
- **Node Path Routing**: Calls `route_node_path` to route paths for the current node.
- **Phase-1 Completion**: Logs completion of Routing Phase-1.
- **PE Meta Condensation**: Collapses shadow PEs metadata into the physical region.
- **Route Pair Creation**: Makes source-destination pairs with local PE IDs for the Benes router for both data and predicate paths.
- **Benes Router**: Starts the Benes router for each block and path (including predicate paths).
- **Phase-2 Completion/Failure**: Logs completion or failure of Routing Phase-2 and updates `data_path_scbs` or `pred_path_scbs` accordingly.
- **Routing Status**: Reports overall routing success or failure.
